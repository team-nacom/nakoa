# 나무컴퍼스 고유 문법: 글상자
텍스트의 특정 부분을 나무컴퍼스에서 제공하는 글상자로 지정할 수 있습니다.
글상자는 일반적으로 다음과 같은 문법을 사용합니다.
```
:::<글상자 종류>[<글상자 제목>]
<글상자 내용>
:::
```
* 콜론(`:`) 세 개 이상, `<글상자 종류>`, `>글상자 제목>` 등을 띄어쓰기 없이 이어서 글상자를 엽니다.
* 여는 줄과 같은 수의 콜론을 적어서 글상자를 닫습니다.

`<글상자 종류>`에는, 빈칸이나 특수문자를 포함하지 않는 한 글자 이상의 영문 문자열을 넣어야 합니다. 나무컴퍼스 편집기에서 지정된 글상자 종류 이외의 문자열을 넣으면, 일반 글상자가 표시됩니다.

```
:::a
여기에 글상자 내용이 들어갑니다.
아쉽게도 위의 a(혹은 다른 문자열)을 넣지 않으면 글상자가 만들어지지 않습니다.
:::
```

한 글상자 안에 다른 글상자를 넣을 수 있습니다. 이 경우, 아래와 같이 바깥쪽 글상자의 콜론 갯수가 안쪽 글상자의 콜론 갯수보다 많아야 합니다.
```
:::::exercise[1]
페르마의 마지막 정리는 1995년, 앤드류 와일즈에 의해 증명되었다. 그 증명법은 다음과 같다.
:::expand[페르마의 마지막 정리의 증명]
여백이 부족하기 때문에 생략한다.
:::
페르마의 마지막 정리를 사용하여, $\sqrt[3]{2}$ 가 무리수임을 증명하여라.
:::::
```

## 지정된 글상자 종류
특수한 디자인이 지정된 글상자 종류는 다음과 같습니다.

* 연습문제(`<글상자 종류>` = `exercise`)

```
:::exercise[1]
연습문제 내용
:::
```

* 접히는 글(`<글상자 종류>` = `expand`)

```
:::expand[접히는 글 제목]
접히는 글 내용
:::
```

## 주의사항
* 글상자 안에서 글머리(`#`, `##` 등)를 사용하지 마세요.

# 나무컴퍼스 고유 문법: 그 외

## 번호를 달지 않는 제목
참고문헌 등 굳이 번호를 달거나 목차에 표시하고 싶지 않은 섹션이 있을 수 있습니다. 글머리 앞에 다음과 같이 `+`를 3번 반복 표시하여 그 글머리를 번호 매기기에서 제외할 수 있습니다.

```
# +++참고문헌
```


만의 하나, 글머리 앞에 의도적으로 +를 3개 이상 달고 싶다면 다음과 같이 빈 코드 환경 혹은 빈 링크를 추가해서 글머리에 번호를 매길 수 있습니다.

```
# ` `+++플러스 3개 사용

# []()+++플러스 3개 사용
```
