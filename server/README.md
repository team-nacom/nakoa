# Nakoa Server

API server will run on port `3885` while developing in local enviornment. In the production server, it will listen to `3884` as nginx proxies all connection on port `3885` to port `3884`. nginx will also take care of SSL configuration, so server need not to set up SSL.

Note that the api call is run on the users' side, not on the server. This means the API server must be open and listen to public.

Server connects to Atlas MongoDB. You can set up your local mongodb if you'd like.


## Configuration

To connect to the Atlas MongoDB, you would need a valid username and password, generated by the system admin. If you have a valid credential, create a file `.env` in `server/`, and save your credential in the following form:

```
DB_USER=foo
DB_PASS=password1234
```

You can set `S3_BUCKET` variable if you want to connect to a S3 bucket. A valid AWS S3 credential for the provided bucket should be set up in your local device. Refer to [AWS Docs](https://docs.aws.amazon.com/sdk-for-javascript/v3/developer-guide/getting-started-nodejs.html) for details.

Also, the production server will have different configurations (i.e. port, allowed CORS origin), so it will have an extra `MODE` variable in `server/.env`.

The production server will have `server/.env` like this:
```
MODE=production
DB_USER=foo
DB_PASS=password1234
S3_BUCKET=bucketname
```

If you want to use local MongoDB, you can add `USE_LOCAL_DB` variable to 1, without specifying DB credential. Server will connect to `nacom` collection. refer to `server/src/models/atlas.ts` for detail.

Fully configured developer's `server/.env` will look like this:
```
DB_USER=username
DB_PASS=password1234
S3_BUCKET=nacom-dev
USE_LOCAL_DB=true
LOCAL_DB_STR=dbstring
```

## How to run

To build the server, run `yarn build`.

To run the server, run `yarn start`.

To run the server which updates on changes of code, run `yarn watch`. It uses nodemon to update

Note that yarn scripts will load dotenv configuration by command line parameters. If you'd like to run the custom script, you need to load `dotenv/config`.
