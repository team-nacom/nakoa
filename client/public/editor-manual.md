# 나무컴퍼스 마크다운 문법 소개

나무컴퍼스 마크다운 형식을 따라서 작성하면 다채로운 서식을 지정할 수 있습니다.
나무컴퍼스 마크다운은, 가독성을 해치지 않으면서 텍스트만을 이용해서 서식이나 컨텐츠를 직관적으로 표현하는 서식 지정 문법인 마크다운에 기반을 두고 있습니다.

마크다운 정식 문법이 아닌 나무컴퍼스 고유 문법은 📐로 표시합니다.

## 글머리

각 게시글은 장과 절, 소절로 구분될 수 있으며, 게시글 자체의 제목 외에도 각 장, 절, 소절의 제목(글머리)를 가질 수 있습니다. 샵(`#`)을 1~3개 이어붙이고 중요도(📐)를 지정한 뒤 한 칸 띄우고 제목을 표시하면 장(`#`), 절(`##`), 소절(`###`)의 글머리가 됩니다. 게시글은 주로 다음과 같은 형식으로 작성됩니다.

```
#A 1장 제목
##A 1절 제목
1절 내용

###C 소절 제목
소절 내용

##A 2절 제목
2절 내용

#B 2장 제목
...
```

### 중요도 📐 
글머리에 장, 절, 소절의 중요도를 `A`(중요도 최상)~`E`(중요도 최하)의 다섯 단계로 표시할 수 있습니다. 연속된 샵(`#`) 뒤에 공백 없이 해당 글자를 추가하면 됩니다.

중요도가 표시된 글머리는 자동으로 번호가 매겨지고 목차에 추가됩니다.
장을 추가하지 않고 절을 추가하거나, 장 및 절을 추가하지 않고 소절을 추가하면 글머리 번호가 정상적으로 매겨지지 않을 수 있습니다.

```
#A 중요도 최상
#B 중요도 상
#C 중요도 중
#D 중요도 하
#E 중요도 최하
```

중요도를 매기지 않을 경우, 중요도는 자동으로 최상(`A`)로 지정됩니다.

중요도에 알파벳 대신 `+`를 표시할 경우, 글머리에 번호가 지정되지 않으며, 목차에 추가되지 않습니다. 참고문헌과 같은 부분을 표시할 때 사용할 수 있습니다.
번호를 달지 않는 글머리는 마지막 장에만 쓸 것을 권장하고 있습니다.

```
#+ 참고문헌
```

글상자나 인용문에 포함된 글머리에는 중요도를 표시할 수 없습니다.

## 글 서식

### 강조

별표(`*`) 두 개로 감싸서 **굵은 글씨**, 한 개로 감싸서 *기울인 글씨*를 지정합니다. ***굵은 기울인 글씨***를 나타내고 싶다면 별표 세 개를 사용합니다.

```
**굵은 글씨**, *기울인 글씨*, ***굵은 기울인 글씨***
```

### 목록

줄의 맨 앞에 `-`, `*`, 혹은 `+` 를 붙여서 번호가 없는 목록을 만들 수 있습니다.
또, 줄을 4칸 들여쓰면 목록 안에 목록을 만들 수 있습니다.
```
- 첫째 항목
- 둘째 항목
    * 하위 목록의 첫째 항목
	* 하위 목록의 둘째 항목
- 셋째 항목
```

한 줄을 넘어가는 항목을 만들고 싶으면, 항목의 둘째 줄 이후의 줄을 2칸 더 들여쓰면 됩니다.
```
* 여러 줄에 걸친
  항목은 이렇게 작성합니다.
    * 하위 목록의 경우에도,
	  방법은 같습니다.
	* 둘째 항목
```

각 줄의 맨 앞을 `1.`로 바꾸면, 번호가 달린 목록을 만들 수 있습니다. 나머지는 번호가 없는 목록과 동일합니다.
```
1. 첫째 항목
2. 둘째 항목
3. 셋째 항목
4. 넷째 항목
    1. 하위 목록의 첫째 항목
	63. 하위 목록의 둘째 항목
	1. 하위 목록의 셋째 항목
```
번호를 순서대로 달지 않아도, `<번호>.`로 시작하는 줄은 자동으로 번호가 매겨집니다.
즉, 이 예시는 다음과 같이 보여집니다.

1. 첫째 항목
2. 둘째 항목
3. 셋째 항목
4. 넷째 항목
    1. 하위 목록의 첫째 항목
	63. 하위 목록의 둘째 항목
	1. 하위 목록의 셋째 항목

101\. 과 같이, `<번호>.` 형식으로 시작하지만 목록을 만들고 싶지 않을 경우, `<번호>\.` 와 같이 입력하면 됩니다.

## 링크

"[팀 나무컴퍼스](http://team-na.com)"와 같이, `[<링크 텍스트>](<링크 주소>)` 형태로 외부 링크를 만들 수 있습니다.
```
[팀 나무컴퍼스](http://team-na.com)
```
링크 주소를 입력했을 때도 외부 링크가 자동으로 생성됩니다.
```
http://team-na.com
```

### 내부 링크 📐

나무컴퍼스 내부 컨텐츠를 참조할 때는, 내부 링크 문법으로 쉽게 링크를 생성할 수 있습니다. 나무컴퍼스의 특정 가이드로 연결하는 링크는 `<링크 주소>` 부분을 `guide:<가이드 번호>`로 지정하면 됩니다.

예를 들어, 10번 가이드로 연결되는 내부 링크를 만드는 구문은 다음과 같습니다.
```
[창조 가이드](guide:10)
```

## 이미지 삽입
이미지 링크가 있는 경우, `![<그림 대체 텍스트>](<이미지 링크>)` 구문으로 이미지 삽입이 가능합니다.
`<그림 대체 텍스트>` 부분을 입력하지 않고 `![](<이미지 링크>)` 로 작성해도 무방합니다.
```
![팀 나무컴퍼스 로고](http://team-na.com/logo.png)
```
나무컴퍼스 마크다운 편집기의 이미지 업로드 기능을 사용하면, 서버에 업로드된 이미지의 링크가 포함된 이미지 삽입 구문이 추가됩니다.

## 표
아래와 같이, 표를 추가할 수 있습니다.

| 1열 | 2열 | 3열 |
| --- | --- | --- |
| 1.1 | 1.2 | 1.3 |
| 2.1 | 2.2 | 2.3 |

이 표는 다음과 같은 방식으로 작성합니다.
```
| 1열 | 2열 | 3열 |
| --- | --- | --- |
| 1.1 | 1.2 | 1.3 |
| 2.1 | 2.2 | 2.3 |
```
둘째 줄에 `---` 가 들어 있어야 표로 인식됩니다.
하이픈(`-`)의 개수는 상관없습니다. 파이프(`|`)의 가로 위치를 맞출 필요도 없습니다.

표의 각 열을 왼쪽, 가운데, 혹은 오른쪽 정렬하고 싶은 경우, 차례대로 둘째 줄의 `---`의 왼쪽, 양쪽, 오른쪽에 콜론(`:`)을 붙이면 됩니다.

```
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
| :--- | :---: | ---: |
| L | C | R |
```

## 소스 코드

백틱(`` ` ``)으로 감싼 부분은 소스 코드 영역으로 지정되어, 같은 수의 백틱으로 닫히기 전까지 글 서식이 적용되지 않습니다.
`````
"C언어에서는 `main`함수가 있어야 합니다." 와 같은 방식으로,
백틱을 한 개 이상 감싸 적용이 가능합니다.

`````

소스 코드 영역에서 백틱을 쓰고 싶은 경우, 연달아 쓰고 싶은 백틱보다 더 많은 백틱을 사용해 감싸면 됩니다.
예를 들어, ``` `` ` `` ```를 사용하면 한 개의 백틱이 코드 영역 안에 표시됩니다.

백틱 세 개 이상으로 이루어진 줄로 감싸서, 블록형 코드 영역을 만들 수도 있습니다.

`````
```
#include<stdio.h>
int main(){
    puts("Hello, World!");
	return 0;
}
```
`````

이 때도 마찬가지로, 코드 영역에서 백틱을 사용하고 싶다면 연달아 쓸 백틱 개수보다 더 많은 개수의 백틱으로 코드 영역을 지정하면 됩니다.

## 수식

수식은 $ax^2 + bx + c = 0$ 과 같은 줄 수식이나,
$$
x = \frac{-b\pm \sqrt{b^2 - 4ac}}{2a}
$$
와 같은 블록 수식을 입력할 수 있습니다.

줄 수식은 문장 아무데서나 추가할 수 있습니다. 달러(`$`)를 사용해서 열고 닫습니다.
블록 수식을 추가할 경우, 달러 두 개(`$$`)를 사용해서 열고 닫습니다.

```
피타고라스의 정리는 다음과 같이 표현할 수 있다.
$a$, $b$, $c$가 직각삼각형의 세 변이며 $c$가 빗변일 때,
$$
a^2 + b^2 = c^2
$$
```
`$$`가 들어간 줄은 반드시 띄워야 합니다.(`$$ a^2 + b^2 = c^2 $$` 처럼 작성한 경우, **줄 수식**으로 적용됩니다.)

수식 영역 내에서는 서식 문법이 적용되지 않으며, $\LaTeX$ 수식 문법이 적용됩니다. 


## 글상자 📐
텍스트의 특정 부분을 나무컴퍼스에서 제공하는 글상자로 지정할 수 있습니다.
글상자는 일반적으로 다음과 같은 문법을 사용합니다.
```
@@@<글상자 종류>[<글상자 제목>]
<글상자 내용>
@@@
```
* 골뱅이(`@`) 3개 이상, `<글상자 종류>`, `<글상자 제목>` 등을 띄어쓰기 없이 이어서 글상자를 엽니다.
* 여는 줄과 같은 수의 골뱅이를 적어서 글상자를 닫습니다.

`<글상자 종류>[<글상자 제목>]`은 생략할 수 있으며, 이 경우 일반 글상자가 표시됩니다.

```
@@@
여기에 글상자 내용이 들어갑니다.
@@@
```

한 글상자 안에 다른 글상자를 넣을 수 있습니다. 이 때, 안쪽 글상자의 골뱅이 개수는 바깥쪽 글상자의 콜론 개수보다 많아야 합니다.
```
@@@exercise[1]
페르마의 마지막 정리는 1995년, 앤드류 와일즈에 의해 증명되었다. 그 증명법은 다음과 같다.
@@@@expand[페르마의 마지막 정리의 증명]
여백이 부족하기 때문에 생략한다.
@@@@
페르마의 마지막 정리를 사용하여, $\sqrt[3]{2}$ 가 무리수임을 증명하여라.
@@@
```

### 지정된 글상자 종류 📐
나무컴퍼스에서 지정한 특수한 글상자는 다음과 같습니다.

* 연습문제(`<글상자 종류>` = `exercise`)

```
@@@exercise[<연습문제 번호>]
연습문제 내용
@@@
```

* 접히는 글(`<글상자 종류>` = `expand`)

```
@@@expand[접히는 글 제목]
접히는 글 내용
@@@
```

## 특수문자 입력
달러, 괄호, 별표, 샵, 골뱅이 등 특수한 기능을 나타내는 문자를 직접 입력하고 싶다면, 백슬래시(`\`)를 앞에 두고 `\$`, `\(`, `\*`, `\#`, `\@` 등으로 입력하면 됩니다. 백슬래시 자체는 `\\`로 입력합니다.
